# サイトコンテンツ管理

## 監査結果

| 対象 | 変更前 | 問題 | 実装方針 |
| --- | --- | --- | --- |
| Home Hero | 装飾プレースホルダーと文言をtemplateに直書き | 運営者が画像・訴求を更新できない | `SiteSettings`で画像、alt、表示位置、主要文言、CTAを管理。画像未設定時は従来表示へfallback |
| Home精選・ブランドメッセージ | 見出しと紹介文をtemplateに直書き | 掲載内容の更新にコード変更が必要 | `SiteSettings`で主要コピーを管理 |
| 室內設計一覧 | ページ主張と相談CTAをtemplateに直書き | 運営上変更される案内を更新できない | `SiteSettings`でページ見出し、主張、相談文言を管理 |
| 出版品一覧 | 紹介文、見出し、編集メッセージをtemplateに直書き | 刊行方針の更新にコード変更が必要 | `SiteSettings`で主要コピーを管理 |
| Shopトップ | Hero／季節記事の画像と主要コピーをtemplateに直書き | 特集更新を管理画面で完結できない | `SiteSettings`で画像、alt、表示位置、主要コピーを管理 |
| About | メイン画像、紹介、沿革をtemplateに直書き | ブランド紹介を更新できない | `SiteSettings`で画像と本文を管理 |
| 共通ブランド | header／shop logo、OGP画像、footer紹介をstatic/templateに固定 | ブランド素材の更新にデプロイが必要 | `SiteSettings`で差し替え可能にし、未設定時は既存static素材へfallback |
| 連絡先・SNS・LINE | 既存`SiteSettings`で管理済み | なし | 既存項目を継続利用 |
| 作品、出版物、商品 | 各content modelで画像・本文を管理済み | なし | 既存モデルを継続利用 |

ナビゲーション構造、装飾用の英字・番号、フォーム／注文／決済の機能文言は、通常のコンテンツ更新対象ではなく機能仕様と密接なため管理項目にしていません。

## 運用

管理画面の「網站設定」は1レコードだけ作成できます。画像は通常のDjango adminアップロードを使い、環境のdefault storageへ保存されます。本番では既存のCloudflare R2設定がそのまま適用されます。

JPEG、PNG、WebPのみ使用でき、既存の容量・寸法検証とメタデータ除去／再エンコード処理を通ります。Hero画像は縦長・横長とも`object-fit: cover`で枠を保ち、「圖片位置」で被写体の基準位置を選べます。

画像項目を空にすると、Home／Shop／Aboutは従来の装飾プレースホルダー、logo／OGPは既存static画像へ戻ります。追加した文言にはmigration時に現行文言が設定されるため、既存データと公開表示は維持されます。
